Risks
- Ketergantungan pada layanan AI.
- Perubahan API dari AI provider.
- Scope creep saat menambah fitur.
- Biaya operasional AI meningkat.

Assumptions
- Backend menggunakan Go.
- Frontend menggunakan Next.js.
- PostgreSQL sebagai database utama.
- OpenCode digunakan sebagai AI coding assistant.
- Dokumentasi menjadi source of truth.
