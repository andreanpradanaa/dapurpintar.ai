# Lessons Learned

Beberapa pembelajaran penting selama Milestone 0:

- Dokumentasi sebaiknya disiapkan sebelum implementasi kode.
- OpenCode akan bekerja lebih efektif dengan prompt kecil dan konteks yang jelas.
- Struktur repository yang baik sejak awal akan mengurangi refactoring di masa depan.
- AI sebaiknya digunakan sebagai engineering partner, bukan hanya code generator.
- Workflow yang terdokumentasi membuat proses pengembangan lebih konsisten.
- Dokumentasi menjadi single source of truth untuk seluruh proyek.
