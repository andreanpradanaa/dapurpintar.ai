# Lessons Learned

- Dokumentasi sejak awal mempercepat pengambilan keputusan.
- Scope produk menjadi lebih jelas.
- Prioritas fitur dapat ditentukan secara objektif.
- AI Agent akan memiliki konteks yang lebih lengkap.
- Risiko scope creep dapat dikurangi.

---

# Exit Criteria

Milestone 1 dianggap selesai apabila:

- Seluruh dokumen telah selesai.
- Seluruh GitHub Issue M1 ditutup.
- Tidak ada blocker kritis.
- Tim menyetujui dimulainya Milestone 2.

Semua kriteria telah terpenuhi.
