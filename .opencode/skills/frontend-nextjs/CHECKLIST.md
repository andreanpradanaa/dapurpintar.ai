# Frontend Next.js Checklist

- [ ] Uses design system tokens and components.
- [ ] Data flows through the typed API client.
- [ ] Error handling uses M6 stable codes.
- [ ] Loading, empty, and error states present.
- [ ] AI surfaces degrade when unavailable.
- [ ] Session auth via cookie; no tokens in client storage.
- [ ] Accessibility verified on key flows.
- [ ] Matches acceptance criteria.
- [ ] No backend shape assumptions outside the contract.
