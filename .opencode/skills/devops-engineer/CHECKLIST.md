# DevOps Engineer Checklist

- [ ] `.env.example` documents every variable with meaning and default.
- [ ] No secret values in code, logs, or committed files.
- [ ] Startup validates configuration and fails fast.
- [ ] Telemetry is correlated and redacted.
- [ ] Alerts exist for availability, errors, latency, and AI quota.
- [ ] Backup restore is verified on a schedule.
- [ ] RPO/RTO are documented and tested.
- [ ] Migrations run before release and are non-destructive.
- [ ] Rollback path exists.
- [ ] Dependencies pinned and scanned.
- [ ] Runbooks updated after incidents.
