# Technical Writer Checklist

- [ ] Purpose and status block at top.
- [ ] Headings reflect document purpose.
- [ ] Facts in tables, rationale in prose.
- [ ] Code examples match the real API/backend.
- [ ] Decision IDs referenced correctly.
- [ ] Terminology consistent with other docs.
- [ ] Repository-relative links correct.
- [ ] Milestone names and statuses match the milestone list.
- [ ] Dependent documents updated in the same change.
