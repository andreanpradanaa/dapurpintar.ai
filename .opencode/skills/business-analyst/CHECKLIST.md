# Business Analyst Checklist

- [ ] Requirement names the persona and outcome.
- [ ] Assumptions are explicit and validated.
- [ ] Journey includes trigger, actions, fallbacks, failure paths.
- [ ] Requirement is measurable and testable.
- [ ] Edge cases called out.
- [ ] Story links to a journey or validated need.
- [ ] AI behavior boundaries stated.
- [ ] Respects bounded contexts and API contract.
- [ ] Maps to a roadmap milestone.
