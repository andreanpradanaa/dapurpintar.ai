# Solution Architect Checklist

## When proposing a decision

- [ ] Decision Register ID assigned (M4-DEC-XXX) with correct status.
- [ ] Context, decision, consequences, status, references written.
- [ ] Alternatives considered and rationale recorded.
- [ ] Superseded decisions referenced.

## When a milestone is implemented

- [ ] Blocking decisions are resolved or explicitly documented as pending.
- [ ] API contract, database schema, backend layout, and roadmap all agree.
- [ ] No silent reopen of an approved decision.
- [ ] Diagrams match code and docs.
- [ ] Milestone list and roadmap are updated.

## When reviewing a milestone

- [ ] Delivered artifacts match the milestone's deliverables.
- [ ] DoR/DoD from M4 readiness applied.
- [ ] Sign-off recorded before next milestone starts.
- [ ] Follow-ups captured as issues.
