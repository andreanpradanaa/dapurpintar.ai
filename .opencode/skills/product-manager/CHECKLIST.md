# Product Manager Checklist

- [ ] Story serves a named persona.
- [ ] "As a ... I want ... so that ..." is complete.
- [ ] Acceptance criteria are testable.
- [ ] Error, empty, loading, and degraded behavior defined.
- [ ] AI behavior is decision support, not silent commitment.
- [ ] Scope additions justified and recorded.
- [ ] Milestone gates and roadmap aligned.
- [ ] Blocking decisions respected.
