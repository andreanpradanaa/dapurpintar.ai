# Documentation Rules

> Aturan penulisan dan pemeliharaan dokumentasi.

## Prinsip

- Dokumentasi ditulis untuk pembaca, bukan penulis
- Selalu perbarui dokumen saat kode berubah
- Gunakan Bahasa yang konsisten

## Struktur Dokumentasi

- Konteks: `contexts/`
- Keputusan: `templates/adr.md`
- API: `templates/api.md`

## Standar Format

- Gunakan Markdown
- Judul hierarki (H1 → H2 → H3)
- Sertakan contoh kode bila perlu
